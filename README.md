# Моё расписание

Сайт для просмотра расписания пар нескольких групп с возможностью добавлять домашние задания и личные заметки к каждой паре.

## Возможности

- **Выбор группы**: при первом открытии сайт спрашивает, чья группа расписание — выбор запоминается в браузере, и в следующий раз сайт сразу открывается на нужной группе, без повторного выбора. Сменить группу позже можно через меню «Ещё» → «Сменить группу». У каждой группы — свои домашние задания, заметки, записи и скрытые пары, они не смешиваются.
- Расписание по дням недели (Пн–Сб) с временем, аудиторией и преподавателем.
- Пары с несколькими параллельными занятиями (подгруппы, чередование по чётности недели) показываются обеими секциями — неактивная по текущей чётности слегка затемняется. Переключатель «Неделя: Нечётная/Чётная» наверху меняет, какая секция считается активной.
- **Занятия на конкретные даты** (например, «Основы российской государственности» с приглашённым лектором раз в несколько недель, или предмет, который идёт только до/после определённой даты) показываются только на той реальной неделе, когда они действительно есть — расписание не показывает несовместимые варианты одновременно. Определяется автоматически по сегодняшней дате, как и чётность недели.
- Клик по паре открывает поля **«Домашнее задание»** и **«Заметка»** — сохраняются автоматически в браузере (localStorage), без сервера и регистрации.
- Отметка «Выполнено» и отдельная вкладка **«Домашние задания»** со сводным списком по всем дням (счётчик невыполненных заданий в шапке).
- Баннер «Сейчас / Следующая пара» показывает текущее занятие по реальному времени.
- Светлая/тёмная тема (кнопка переключения темы), экспорт и импорт заметок в JSON-файл (меню «Ещё») — удобно для резервной копии или переноса на другое устройство.
- **Аудиозапись пары**: кнопка «Записать пару» у каждой секции пары включает запись с микрофона (с таймером), запись сохраняется прямо в браузере (IndexedDB) — можно прослушать, скачать или удалить. Одновременно можно записывать только одну пару; остальные кнопки записи на это время блокируются.
- **Устанавливается как приложение** (PWA): значок на главном экране телефона, отдельное окно без адресной строки браузера, работает офлайн после первого открытия.
- **Скрытие ненужных пар**: если студент не ходит на какую-то пару (например, выбрал другой язык или подгруппу, или освобождён от предмета), внутри пары есть кнопка «Не хожу — скрыть эту пару» — пара пропадает из расписания, баннера «Сейчас/Следующая», точек с напоминаниями и списка домашних заданий. Кнопка «Показать скрытые пары» (появляется, когда что-то скрыто) временно возвращает скрытые пары в список приглушённым цветом с кнопкой «Восстановить».
- **Разовые изменения на одну неделю** (пары иногда переносят/заменяют): кнопка «Пары не будет на этой неделе» у пары убирает её только из текущей недели — на следующей она появится сама как обычно. Кнопка «Добавить пару на эту неделю» внизу списка позволяет вписать внеплановое занятие (замену, перенос) — предмет, номер пары, тип, преподавателя, аудиторию; у такой пары тоже работают домашнее задание, заметки, тема и запись, а удаляется она кнопкой «Удалить эту пару».
- **Тема занятия**: поле «Тема занятия» у каждой пары — что именно было пройдено (заполняется после занятия), показывается прямо на карточке в расписании и в списке домашних заданий, удобно для повторения перед экзаменом.
- **Срок сдачи домашнего задания**: поле «Сдать до» с датой — во вкладке «Домашние задания» просроченные задания подсвечиваются красным, задания на сегодня/завтра — жёлтым, список сам сортируется по сроку.
- **Конспект / материалы лекции**: кнопка «Добавить конспект лекции» раскрывает отдельное большое поле — можно вставить текст лекции, определения, формулы, отдельно от короткой личной заметки.

## Установка на главный экран

- **Android / Chrome**: в меню «Ещё» сайта появится пункт «Установить на главный экран» — нажмите его и подтвердите установку (либо используйте пункт меню браузера «Установить приложение»).
- **iPhone / Safari**: пункт «Установить на главный экран» в меню «Ещё» покажет инструкцию — кнопка «Поделиться» внизу экрана → «На экран «Домой»» → «Добавить». Safari не позволяет установить сайт автоматически по кнопке — это ограничение самого iOS.

После установки приложение открывается отдельной иконкой, без адресной строки браузера, со своим экраном загрузки (подобраны под iPhone 13/14/15 и их Plus/Pro Max версии), и продолжает работать офлайн (расписание, домашние задания и заметки не требуют интернета; для записи аудио в первый раз всё равно нужен доступ к микрофону).

**Если значок уже был добавлен на главный экран раньше** и открывается как обычная вкладка Safari (с адресной строкой), а не отдельным окном — iOS запоминает поведение на момент добавления и не обновляет его сама. Удалите старый значок с главного экрана (зажать → «Удалить приложение») и добавьте заново через «Поделиться» → «На экран «Домой»».

## Запуск

Сайт полностью статический — не требует сборки или сервера.

- Откройте `index.html` напрямую в браузере, либо
- разместите папку на GitHub Pages / любом статическом хостинге.

Для записи аудио браузер должен открывать сайт по HTTPS (или `localhost`) — это требование самих браузеров для доступа к микрофону.

## Как изменить расписание или добавить группу

Отредактируйте `schedule-data.js` — там массив `GROUPS`, каждый элемент которого описывает одну группу (название, код, дни и пары) обычным JS-объектом с комментариями. Чтобы добавить новую группу, скопируйте объект существующей группы внутри массива и замените данные — она сама появится в экране выбора группы. Логика (`app.js`) и вёрстка (`index.html`, `style.css`) менять не нужно.

Важно: у каждой группы свой `id` (короткий идентификатор) — под ним хранятся домашние задания и заметки этой группы, поэтому менять `id` уже используемой группы не стоит (данные «потеряются» для сайта, хоть физически и останутся в хранилище браузера).

Для занятий, которые идут не каждую неделю, есть поля `activeDates` (только в эти даты), `exceptDates` (каждую неделю, кроме этих дат), `fromDate`/`toDate` (с какой по какую дату) — формат `"ДД.ММ"`, год берётся из текущей недели.

## Хранение данных и перенос между устройствами

Все текстовые данные (домашние задания, темы, сроки сдачи, конспекты, заметки, скрытые пары, разовые изменения на неделю) хранятся только в `localStorage` того браузера, где их вводили — **между телефоном и компьютером они сами не синхронизируются**, это разные браузеры/устройства.

Чтобы перенести данные на другое устройство: меню «Ещё» → **«Экспорт (перенос на другое устройство)»** — скачается один JSON-файл со всем сразу (задания, скрытые и разово изменённые пары). Перешлите файл на другое устройство любым удобным способом (AirDrop, Telegram «Избранное», почта себе и т.п.) и на нём откройте меню «Ещё» → **«Импорт (с другого устройства)»**, выберите файл. Данные объединяются с уже существующими на устройстве, ничего не затирая.

Аудиозаписи хранятся отдельно, в `IndexedDB` того же браузера (могут занимать существенно больше места, чем текст), и **не входят в экспорт/импорт** — их придётся переносить вручную, скачивая кнопкой «Скачать» у каждой записи и пересылая файл.

# Моё расписание

Сайт для просмотра расписания пар нескольких групп с возможностью добавлять домашние задания и личные заметки к каждой паре.

## Возможности

- **Выбор группы**: при первом открытии сайт спрашивает, чья группа расписание — выбор запоминается в браузере, и в следующий раз сайт сразу открывается на нужной группе, без повторного выбора. Сменить группу позже можно через меню «Ещё» → «Сменить группу». У каждой группы — свои домашние задания, заметки, записи и скрытые пары, они не смешиваются.
- Расписание по дням недели (Пн–Сб) с временем, аудиторией и преподавателем.
- Пары с несколькими параллельными занятиями (подгруппы, чередование по чётности недели) показываются обеими секциями — неактивная по текущей чётности слегка затемняется. Переключатель «Неделя: Нечётная/Чётная» наверху меняет, какая секция считается активной.
- **Занятия на конкретные даты** (например, «Основы российской государственности» с приглашённым лектором раз в несколько недель, или предмет, который идёт только до/после определённой даты) показываются только на той реальной неделе, когда они действительно есть — расписание не показывает несовместимые варианты одновременно. Определяется автоматически по сегодняшней дате, как и чётность недели.
- Клик по паре открывает поля **«Домашнее задание»** и **«Заметка»** — сохраняются автоматически в браузере (localStorage), без сервера и регистрации.
- Отметка «Выполнено» и отдельная вкладка **«Домашние задания»** со сводным списком по всем дням (счётчик невыполненных заданий в шапке).
- Баннер «Сейчас / Следующая пара» показывает текущее занятие по реальному времени.
- Светлая/тёмная тема (кнопка переключения темы), экспорт и импорт заметок в JSON-файл (меню «Ещё») — удобно для резервной копии или переноса на другое устройство.
- **Аудиозапись пары**: кнопка «Записать пару» у каждой секции пары включает запись с микрофона (с таймером), запись сохраняется прямо в браузере (IndexedDB) — можно прослушать, скачать или удалить. Одновременно можно записывать только одну пару; остальные кнопки записи на это время блокируются.
- **Устанавливается как приложение** (PWA): значок на главном экране телефона, отдельное окно без адресной строки браузера, работает офлайн после первого открытия.
- **Скрытие ненужных пар**: если студент не ходит на какую-то пару (например, выбрал другой язык или подгруппу, или освобождён от предмета), внутри пары есть кнопка «Не хожу — скрыть эту пару» — пара пропадает из расписания, баннера «Сейчас/Следующая», точек с напоминаниями и списка домашних заданий. Кнопка «Показать скрытые пары» (появляется, когда что-то скрыто) временно возвращает скрытые пары в список приглушённым цветом с кнопкой «Восстановить».
- **Разовые изменения на одну неделю** (пары иногда переносят/заменяют): кнопка «Пары не будет на этой неделе» у пары убирает её только из текущей недели — на следующей она появится сама как обычно. Кнопка «Добавить пару на эту неделю» внизу списка позволяет вписать внеплановое занятие (замену, перенос) — предмет, номер пары, тип, преподавателя, аудиторию; у такой пары тоже работают домашнее задание, заметки, тема и запись, а удаляется она кнопкой «Удалить эту пару».
- **Тема занятия**: поле «Тема занятия» у каждой пары — что именно было пройдено (заполняется после занятия), показывается прямо на карточке в расписании и в списке домашних заданий, удобно для повторения перед экзаменом.
- **Срок сдачи домашнего задания**: поле «Сдать до» с датой — во вкладке «Домашние задания» просроченные задания подсвечиваются красным, задания на сегодня/завтра — жёлтым, список сам сортируется по сроку.
- **Конспект / материалы лекции**: кнопка «Добавить конспект лекции» раскрывает отдельное большое поле — можно вставить текст лекции, определения, формулы, отдельно от короткой личной заметки.
- **Уведомления о горящих дедлайнах**: наверху сайта появляется баннер «Просрочено: N · Горит: N», если есть невыполненные задания со сроком сдачи сегодня/завтра или просроченные — виден на любой вкладке, клик по нему открывает список домашних заданий. Дополнительно в меню «Ещё» можно включить пункт «Уведомления о дедлайнах» — браузер спросит разрешение и будет присылать push-уведомление за задание, как только оно станет «горящим» или просроченным (без повторов для одного и того же задания). Тот же переключатель включает и уведомление «Пара скоро начнётся» — придёт за несколько минут до начала пары. Работает, пока сайт открыт (во вкладке или как установленное приложение) — см. ограничение ниже.
- **Ярлыки на главном экране**: при установке приложения на Android долгое нажатие на значок предлагает быстрые ссылки «Домашние задания» и «Записи» — открывают сразу нужную вкладку, без прохода через расписание.
- **Поиск по домашним заданиям**: строка поиска в верхней части вкладки «Домашние задания» ищет по предмету, теме занятия, тексту задания, заметке и конспекту одновременно.
- **Экспорт дедлайнов в календарь**: меню «Ещё» → «Дедлайны в календарь (.ics)» скачивает файл со всеми сроками сдачи (у кого проставлена дата «Сдать до») — импортируется в Google Calendar, Apple Calendar, Outlook и т.п., с напоминанием за день.
- **Статистика**: меню «Ещё» → «Статистика» — сводка по всем домашним заданиям (всего, выполнено, осталось, просрочено, горит), скрытым/отменённым на неделю парам, внеплановым парам и аудиозаписям.
- **Цветные метки предметов**: у каждого предмета — свой стабильный цвет (кружок рядом с названием) в расписании и списке домашних заданий, для быстрой визуальной ориентации.
- **QR-код для разового переноса данных**: меню «Ещё» → «Показать QR-код» на одном устройстве и «Сканировать QR-код» на другом — камера считывает код и сразу импортирует данные, без файлов и проводов. Разовое действие, не автоматическое — для постоянной синхронизации см. следующий пункт.
- **Постоянная синхронизация между устройствами**: меню «Ещё» → «Синхронизация» — один раз свяжите телефон и компьютер QR-кодом (или кодом вручную), и дальше все изменения (задания, темы, заметки, скрытые и добавленные пары) сами появляются на обоих устройствах, в реальном времени, без повторного экспорта/импорта — см. подробности и настройку ниже.
- Разовые изменения на неделю старше ~4 месяцев автоматически удаляются из хранилища при открытии сайта, чтобы не копить в браузере данные по давно прошедшим неделям.
- **Фото к паре**: кнопка «Добавить фото» у каждой пары — снимок с камеры (доска, методичка, раздатка) или выбор из галереи, хранится в браузере (IndexedDB), миниатюры показываются прямо в паре, клик открывает на весь экран, удаляются по отдельности. Как и аудиозаписи, в экспорт/импорт/QR/синхронизацию не входят — слишком большой объём.
- **Прогресс текущей пары**: в баннере «Сейчас N-я пара» — тонкая полоска, показывающая, какая часть пары уже прошла.
- **Прогресс по домашним заданиям**: на вкладке «Домашние задания» — полоска «N из M выполнено (X%)» над списком, сводка по всем текущим заданиям.

## Установка на главный экран

- **Android / Chrome**: в меню «Ещё» сайта появится пункт «Установить на главный экран» — нажмите его и подтвердите установку (либо используйте пункт меню браузера «Установить приложение»).
- **iPhone / Safari**: пункт «Установить на главный экран» в меню «Ещё» покажет инструкцию — кнопка «Поделиться» внизу экрана → «На экран «Домой»» → «Добавить». Safari не позволяет установить сайт автоматически по кнопке — это ограничение самого iOS.

После установки приложение открывается отдельной иконкой, без адресной строки браузера, со своим экраном загрузки (подобраны под iPhone 13/14/15 и их Plus/Pro Max версии), и продолжает работать офлайн (расписание, домашние задания и заметки не требуют интернета; для записи аудио в первый раз всё равно нужен доступ к микрофону).

**Если значок уже был добавлен на главный экран раньше** и открывается как обычная вкладка Safari (с адресной строкой), а не отдельным окном — iOS запоминает поведение на момент добавления и не обновляет его сама. Удалите старый значок с главного экрана (зажать → «Удалить приложение») и добавьте заново через «Поделиться» → «На экран «Домой»».

## Запуск

Сайт полностью статический — не требует сборки или сервера.

- Откройте `index.html` напрямую в браузере, либо
- разместите папку на GitHub Pages / любом статическом хостинге.

Для записи аудио браузер должен открывать сайт по HTTPS (или `localhost`) — это требование самих браузеров для доступа к микрофону.

## Как изменить расписание или добавить группу

Отредактируйте `schedule-data.js` — там массив `GROUPS`, каждый элемент которого описывает одну группу (название, код, дни и пары) обычным JS-объектом с комментариями. Чтобы добавить новую группу, скопируйте объект существующей группы внутри массива и замените данные — она сама появится в экране выбора группы. Логика (`app.js`) и вёрстка (`index.html`, `style.css`) менять не нужно.

Важно: у каждой группы свой `id` (короткий идентификатор) — под ним хранятся домашние задания и заметки этой группы, поэтому менять `id` уже используемой группы не стоит (данные «потеряются» для сайта, хоть физически и останутся в хранилище браузера).

Для занятий, которые идут не каждую неделю, есть поля `activeDates` (только в эти даты), `exceptDates` (каждую неделю, кроме этих дат), `fromDate`/`toDate` (с какой по какую дату) — формат `"ДД.ММ"`, год берётся из текущей недели.

## Хранение данных и перенос между устройствами

Все текстовые данные (домашние задания, темы, сроки сдачи, конспекты, заметки, скрытые пары, разовые изменения на неделю) хранятся только в `localStorage` того браузера, где их вводили — **между телефоном и компьютером они сами не синхронизируются**, это разные браузеры/устройства.

Чтобы перенести данные на другое устройство: меню «Ещё» → **«Экспорт (перенос на другое устройство)»** — скачается один JSON-файл со всем сразу (задания, скрытые и разово изменённые пары). Перешлите файл на другое устройство любым удобным способом (AirDrop, Telegram «Избранное», почта себе и т.п.) и на нём откройте меню «Ещё» → **«Импорт (с другого устройства)»**, выберите файл. Данные объединяются с уже существующими на устройстве, ничего не затирая.

Аудиозаписи и фото к парам хранятся отдельно, в `IndexedDB` того же браузера (могут занимать существенно больше места, чем текст), и **не входят в экспорт/импорт/синхронизацию** — аудиозаписи придётся переносить вручную, скачивая кнопкой «Скачать» у каждой записи; фото можно только пересматривать/удалять на том устройстве, где они были добавлены.

Кроме файла, тот же набор данных (без аудиозаписей) можно перенести **разово** через **QR-код** (меню «Ещё» → «Показать QR-код» / «Сканировать QR-код») — быстрее для небольшого объёма данных, но при большом объёме (много длинных конспектов и заданий) не поместится в один код, тогда сайт предложит использовать файл.

## Синхронизация между устройствами (постоянная)

В отличие от разового QR-переноса выше, здесь телефон и компьютер один раз связываются между собой, и дальше **все изменения появляются друг у друга сами**, в реальном времени, даже если устройства не открыты одновременно (данные просто ждут в облаке до следующего открытия сайта на втором устройстве).

Так как сайт статический (без своего сервера), для этого используется бесплатное облачное хранилище **Firebase Realtime Database** от Google — минимальный, но реальный бэкенд, который нужно один раз подключить к сайту.

### Как настроить (один раз, минут 5)

1. Откройте **https://console.firebase.google.com**, войдите с любым Google-аккаунтом → «Add project» / «Создать проект» → придумайте любое имя → на шаге про Google Analytics можно отключить (не нужен) → «Create project».
2. В меню слева: **Build → Realtime Database → Create Database**. Выберите любой регион → на шаге про правила безопасности выберите **«Start in locked mode»** (правила зададим вручную ниже — это безопаснее, чем открытый test mode).
3. Там же, в разделе Realtime Database, откройте вкладку **«Rules»** и вставьте вместо содержимого:
   ```json
   {
     "rules": {
       "sync": {
         "$code": {
           ".read": true,
           ".write": true
         }
       }
     }
   }
   ```
   Нажмите **Publish**. Это ограничивает доступ только путём `sync/<код>` — без знания конкретного кода синхронизации (длинная случайная строка) прочитать или изменить чужие данные нельзя.
4. Слева вверху — значок шестерёнки → **Project settings** → вкладка **General** → прокрутите до «Your apps» → нажмите значок **`</>`** (Web) → впишите любое имя приложения → **Register app**. Появится блок кода с объектом `firebaseConfig` — там будут поля `apiKey`, `authDomain`, `databaseURL`, `projectId`, `storageBucket`, `messagingSenderId`, `appId`.
5. Откройте в репозитории файл **`firebase-config.js`** и вставьте эти значения в соответствующие поля объекта `window.FIREBASE_CONFIG`. Это не секретные данные — их можно спокойно закоммитить, доступ защищён правилами (шаг 3), а не секретностью конфига.
6. Сохраните, задеплойте сайт (или откройте `index.html` локально) — в меню «Ещё» пункт «Синхронизация» теперь предложит «Это первое устройство — создать пару».

### Как пользоваться

- На первом устройстве: меню «Ещё» → «Синхронизация» → **«Это первое устройство — создать пару»** — появится QR-код и код текстом.
- На втором устройстве: меню «Ещё» → «Синхронизация» → **«У меня есть код — сканировать QR»** (или «Ввести код вручную», если камеры нет под рукой) — отсканируйте QR с первого устройства.
- Готово — зелёная точка и надпись «Синхронизировано» означают, что оба устройства теперь обмениваются изменениями автоматически. Тот же код можно отсканировать на третьем, четвёртом и т.д. устройстве — все они будут синхронизированы между собой.
- «Отключить синхронизацию» в том же окне останавливает обмен на этом устройстве (уже полученные данные остаются).

### Как это работает и ограничения

- Синхронизируются: домашние задания, темы, сроки сдачи, конспекты, заметки, отметки «выполнено», скрытые пары и разовые изменения на неделю. **Аудиозаписи и фото к парам не синхронизируются** (слишком большой объём для этого способа) — для аудиозаписей по-прежнему нужен файл экспорта записи, а фото видны только на том устройстве, где были добавлены.
- Правки объединяются по каждой паре отдельно — если на одном устройстве отредактировать одну пару, а на другом в это же время другую, обе правки сохранятся. Если оба устройства одновременно (в течение нескольких секунд, до реального обмена данными) отредактировать **одну и ту же** запись — сохранится более поздняя по времени правка, вторая будет потеряна (обычный компромисс для бессерверной синхронизации без ручного разрешения конфликтов).
- Бесплатный план Firebase (Spark) с огромным запасом хватает для одного человека на годы вперёд — конкретно этот сайт хранит лишь тексты (без аудио), это существенно меньше 1 МБ.
- Код синхронизации — длинная случайная строка (32 символа), знание которой равносильно доступу к данным этой «пары устройств». Не публикуйте код и QR-код синхронизации публично.
- Работает как в обычной вкладке браузера, так и в установленном как приложение виде; требует подключения к интернету в момент, когда синхронизация происходит (изменения, сделанные офлайн, досинхронизируются, когда интернет появится и сайт снова откроется).

## Об уведомлениях о дедлайнах

Сайт полностью статический — без своего сервера отправлять push-уведомления, когда приложение полностью закрыто (как это делают, например, мессенджеры), технически невозможно: для этого нужен push-сервер и подписка (VAPID). Поэтому реализован реалистичный для статического сайта вариант:

- Баннер сверху страницы — работает всегда, без каких-либо разрешений, просто показывает счётчик горящих/просроченных заданий.
- Настоящие уведомления через `Notification API` — работают, пока сайт открыт хотя бы в одной вкладке или как установленное приложение (даже свёрнутое/в фоне). Если полностью закрыть сайт и не открывать долгое время — уведомление не придёт, пока вы не откроете сайт снова (тогда баннер и, если задание всё ещё «горит», уведомление появятся сразу).
- **На iPhone уведомления (не баннер) работают только если сайт установлен на главный экран** («На экран «Домой»» через Safari → «Поделиться») — в обычной вкладке Safari iOS не даёт сайтам присылать уведомления вообще. Баннер наверху страницы при этом работает в любом случае.
